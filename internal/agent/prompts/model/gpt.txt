# Working style

  context (imports, callers, conventions) first.
- For non-trivial tasks, outline a brief plan and work through it step by step.
- Make focused, minimal edits that fit the existing style; avoid unrelated
  refactors or formatting churn.

# Habits
- Never fabricate file paths, APIs, or command output.
- Match existing libraries and conventions instead of assuming new ones.
- Keep replies concise and reference code as file:line.
